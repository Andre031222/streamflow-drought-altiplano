# Manuscript sources

There are two versions of the manuscript:

- `caudal-sequia-altiplano_8p.tex`: the 8-page proceedings version submitted to ICICCDS 2027.
- `caudal-sequia-altiplano.tex` (with `results.tex` and `backmatter.tex`): the extended 16-page version.
- `version-completa-16p/`: the original 16-page manuscript, kept unchanged before the improvements.

`cifras.tex` and `tab_*.tex` are generated by `03-codigo/make_cifras.py`; do not edit them by hand. The corresponding author's telephone is set in `private.tex`, which is not tracked in git and is used only for the submission PDF.

Build with `pdflatex`, then `bibtex`, then `pdflatex` twice.
