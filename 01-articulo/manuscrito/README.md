# Manuscript sources

- `caudal-sequia-altiplano_crc.tex`: the **final camera-ready version** for the ICICCDS 2027 proceedings (8 pages). Its PDF is `../envio-cmt/ICICCDS2027-51-Vilca-Solorzano-CRC.pdf`.
- `caudal-sequia-altiplano_8p.tex`: the 8-page version submitted for review in September 2026 (superseded).
- `caudal-sequia-altiplano.tex` (with `results.tex` and `backmatter.tex`): an earlier extended 16-page draft (superseded).
- `version-completa-16p/`: the original 16-page manuscript, kept unchanged.

`cifras.tex` and `tab_*.tex` are generated by `03-codigo/make_cifras.py`; do not edit them by hand. Only the camera-ready text is kept consistent with the current numbers; the superseded versions describe the September 2026 run, and their committed PDFs are left as they were. The corresponding author's telephone is set in `private.tex`, which is not tracked in git and is used only for the submission PDF.

Build with `pdflatex`, then `bibtex`, then `pdflatex` twice.
