\section*{Declarations}

\noindent\textbf{Data and code availability.} Daily quality-controlled discharge and catchment polygons are from Andean-GC (Zenodo, doi:\href{https://doi.org/10.5281/zenodo.18035801}{10.5281/zenodo.18035801}; CC~BY~4.0). ERA5 precipitation and temperature were retrieved through the Open-Meteo Historical Weather API \cite{openmeteo}. Additional data came from NASA POWER (MERRA-2 \texttt{PRECTOTCORR}) and GloFAS~v4 reanalysis via the Open-Meteo Flood API. All extracts, caches, result tables and code are released under the MIT license in the repository described in Sect.~\ref{sec:repo}.
